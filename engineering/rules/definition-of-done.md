# Definition of Done

- The change meets the agreed acceptance criteria and stays within scope.
- Existing architecture and conventions are followed; any necessary deviation is explained.
- Relevant authorization, privacy, validation, data integrity, and error cases are handled.
- Relevant project checks were run where available; results and any verification gap are stated accurately.
- The diff has been reviewed for regressions, accidental secrets/data, and unrelated edits.
- Documentation or migration notes are updated when behavior, configuration, or data shape changes.
- If a user or check corrected a real mistake, a generalized lesson was added or merged into `engineering/learnings/codex.md`; otherwise the learnings file stays unchanged.
- Shared/destructive actions remain for a human. The handoff names the change, checks, known risks, and the next human action.
